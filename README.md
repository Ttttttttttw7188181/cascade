# Cascade

Cascade — Android-клиент для Xray с современным интерфейсом в духе INCY
(Material You), обходом DPI, цепочками серверов и управлением раздачей.
Основа — проверенное ядро Xray и Android-клиент
[v2rayNG](https://github.com/2dust/v2rayNG) 2.3.15 (GPL-3.0); интерфейс,
навигация, домашний экран, экраны агрегации, хотспота и авторов написаны
для Cascade. Пакет: `com.narezany.cascade`.

> Cascade не связан с INCY, v2rayNG или их авторами и не использует ассеты
> INCY. Используй приложение только со своими серверами и подписками.

## Что уже работает

- **Домашний экран в стиле INCY:** большая кнопка подключения, статус,
  выбранный сервер, скорость ↓/↑, время сессии и тип сети. Цвета берутся из
  Material You (dynamic color), при отключённом dynamic color используется
  собственная индиго-палитра.
- **VPN-интерфейс** через Android `VpnService` и Xray-core.
- **Протоколы:** VLESS (включая Reality), VMess, Trojan, Shadowsocks,
  SOCKS5, HTTP, WireGuard, Hysteria2. Полные Xray JSON-конфиги тоже
  импортируются.
- **Подписки:** ссылка, QR, буфер обмена, base64/plain-формат, автообновление.
- **Каскад:** отдельный тип профиля «Proxy chain» — можно собрать цепочку
  из нескольких серверов (вход → промежуточный → выход).
- **Фрагментация:** TLS ClientHello или все TCP-пакеты; настраиваются длина,
  интервал и максимальное число фрагментов. Помогает против DPI, которые
  ловят TLS-рукопожатие.
- **Распределение трафика:** «Policy group» с балансировщиком
  `random`, `roundRobin`, `leastPing` или `leastLoad`. Это не торрент-нарезка
  одного TCP-соединения, а распределение новых соединений между серверами.
- **Переключение Wi-Fi ↔ мобильная сеть:** на Android 9+ при смене сети ядро
  перезапускается и туннель восстанавливается. Это failover.
- **Агрегация через внешний SOCKS5-балансир:** подключите локальный
  балансир (например, net-merge или NetCombine) на `127.0.0.1:1080`, включите
  «Агрегацию» — Xray будет подключаться к серверу через него, а балансир
  распределит новые соединения между Wi-Fi и мобильной сетью. Встроенного
  балансира нет: два VPN одновременно Android не разрешает.
- **Раздача VPN через хотспот:** экран «Хотспот» управляет отдельным
  приложением Shizzi через Shizuku и его документированный automation API.
  Нужны Android 11+, Shizuku 13.6+ и включённая автоматизация в Shizzi.
- **Экран авторов и лицензий** со ссылками на upstream-проекты.
- **Per-app proxy, routing, DNS, kill switch-подобное поведение** —
  наследуются от v2rayNG.
- **Свой User-Agent и HTTP-заголовки подписки:** в редактировании подписки
  есть поля `User-Agent` и `Request Headers` (JSON). Через них можно передать
  `X-HWID`, `X-App-Version`, `X-Client` и другие заголовки, которые требует
  твоя панель.

## Ограничения

- **Агрегация — это балансировка по соединениям, а не склейка одного потока.**
  Cascade передаёт исходящие TCP-соединения Xray внешнему SOCKS5-балансиру
  (net-merge, NetCombine и подобным). Балансир распределяет новые соединения
  между Wi-Fi и мобильной сетью, поэтому параллельные загрузки ускоряются.
  Одно TCP-соединение по-прежнему идёт через один канал. Для настоящего
  bonding нужен сервер-агрегатор на VPS — этого в приложении нет.
- **Два VPN одновременно Android не разрешает.** Балансир должен быть
  отдельным приложением/сервисом с локальным SOCKS5-портом, а не вторым VPN.
  Если балансир не запущен, включённая агрегация приведёт к ошибке подключения.
- **Failover не суммирует скорость.** При смене Wi-Fi ↔ мобильная сеть ядро
  перезапускается и туннель восстанавливается на доступном канале.
- **Хотспот требует Shizzi и Shizuku.** Cascade не получает root и не делает
  привилегированную часть сам; он управляет Shizzi через его публичный
  automation API. Без установленного Shizzi, Shizuku 13.6+ и разрешения
  фоновой активности раздача не запустится.
- **Подмены чужого клиента и произвольного HWID для обхода лимита устройств
  здесь нет.** Приложение отправляет свой User-Agent (`Cascade/0.1.0`) и
  позволяет задать заголовки для своей панели. Не используй это, чтобы выдавать
  себя за другое приложение или обходить ограничения чужого сервиса.

## Быстрый старт

1. Установи APK.
2. Добавь подписку или отдельный сервер.
3. Подключись.
4. Если сеть блокирует TLS-рукопожатие: **Настройки → Fragment Settings**,
   включи фрагментацию и попробуй `tlshello`, длину `50-100`, интервал `10-20`.
5. Для каскада: добавь нужные серверы, затем **импорт → Proxy chain** и
   выбери участников цепочки.
6. Для распределения по серверам: **импорт → Policy group**, выбери стратегию
   и серверы/подписку.
7. Для агрегации: запусти SOCKS5-балансир на телефоне, открой
   **Настройки → Сеть и раздача → Агрегация каналов**, укажи хост и порт
   (например, `127.0.0.1:1080`), включи переключатель и перезапусти VPN.
8. Для раздачи: установи [Shizzi](https://github.com/carlelieser/shizzi),
   включи в нём автоматизацию и скопируй токен. Затем открой
   **Настройки → Сеть и раздача → Хотспот с VPN**, вставь токен и включи
   раздачу.

### User-Agent, версия и HWID

В карточке подписки:

- `User-Agent` — строка вида `Cascade/0.1.0` или то, что требует панель.
- `Request Headers` — JSON:

```json
{
  "X-HWID": "00000000-0000-4000-8000-000000000000",
  "X-App-Version": "0.1.0",
  "X-Client": "Cascade"
}
```

Если панель поддерживает произвольный HWID, подставь свой. Это твой
идентификатор устройства; не выдавай его за идентификатор чужого телефона.

## Сборка через GitHub Actions

В репозитории уже есть workflow `.github/workflows/build.yml`. Он:

1. Ставит Java 21 и Android SDK 37.
2. Скачивает заранее собранные native-библиотеки, привязанные к версиям
   v2rayNG 2.3.15 и Xray v26.10.31.
3. Собирает `assemblePlaystoreDebug`.
4. Выкладывает APK в Artifacts.

Порядок:

```bash
git init
git add .
git commit -m "Cascade MVP"
git branch -M main
git remote add origin https://github.com/ТВОЙ_АККАУНТ/cascade.git
git push -u origin main
```

Дальше на GitHub: **Actions → Build Cascade APK → Run workflow**. После
сборки скачай `Cascade-0.1.0-debug` из Artifacts и установи
`Cascade_0.1.0_arm64-v8a.apk` (для большинства телефонов).

Сборка подписана debug-ключом GitHub Runner. Для нормальных обновлений
добавь свой keystore и переключи workflow на `assemblePlaystoreRelease`
(секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).

## Структура

- `V2rayNG/` — Android-проект (Kotlin, Compose, Xray).
- `.github/workflows/build.yml` — сборка APK.
- `AndroidLibXrayLite/`, `hev-socks5-tunnel/` — пустые каталоги upstream
  submodules; в этой сборке native-библиотеки скачиваются готовыми.
